## Notes

### day1

C++ is “**The invisible foundation of everything**”

- Game
- High Frequency Trading
- Self Driving
- GPU Programming
- Database
- Web Browser
- VR
- Low level ML
- Compiler/OS



C++在下面这些方面做得好：

- Handling lots of data（处理大量数据）
- And handling it very efficiently（高效）
- And doing it in an elegant, readable way（优雅）



C++帮助养成更好的开发习惯：

- 我是否使用了合适的方式使用对象？
  - 类型检查、类型安全
- 我是否高效使用了内存？
  - 引用语义、拷贝语义、移动语义
- 我是否修改了不应该修改的内容？

在很多其它语言中则放宽了这些条件。
